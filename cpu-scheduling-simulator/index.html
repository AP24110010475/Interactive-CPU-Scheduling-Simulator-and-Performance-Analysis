CPU Scheduling Algorithms Guide

Non-Preemptive

1. First Come First Serve (FCFS)

Processes are dispatched strictly in order of arrival using a FIFO queue.

  • Pros: Simple to implement, zero starvation.
  • Cons: Convoy effect when a long CPU-bound job arrives first.
Non-Preemptive

2. Shortest Job First (SJF)

Selects the arrived process with the smallest burst time whenever the CPU becomes free.

  • Pros: Provably optimal average waiting time for non-preemptive scheduling.
  • Cons: Can cause starvation for long jobs; burst time must be known/estimated.
Preemptive

3. Shortest Remaining Time First (SRTF)

Preemptive variant of SJF. A newly arrived process preempts the running process if its burst time is smaller than the current remaining time.

  • Pros: Minimum possible average waiting time across all algorithms.
  • Cons: Higher context-switch overhead and potential starvation.
Non-Preemptive

4. Priority Scheduling

Allocates CPU to the arrived process with the highest priority (1 = Highest).

  • Pros: Critical system or real-time tasks run before background tasks.
  • Cons: Indefinite blocking (starvation) of low-priority processes without aging.
Preemptive

5. Round Robin (RR)

Each ready process gets a fixed Time Quantum in cyclic FIFO order before being preempted.

  • Pros: Fair CPU allocation, excellent response time for interactive systems.
  • Cons: Too small quantum increases context-switch overhead; too large degenerates to FCFS.
COA Formulas

Key Performance Equations

  • TAT = CT - AT (Turnaround Time)
  • WT = TAT - BT (Waiting Time)
  • RT = First Start - AT (Response Time)
  • CPU Util = (Σ BT / Total Time) × 100%
  • Throughput = N / Total Time
